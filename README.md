# VocabMax 背單字

純前端、資料存在本機（IndexedDB）的背單字 PWA，可在 iPhone Safari「加入主畫面」當 App 使用。

## 功能
- 學習集：建立／編輯／複製／刪除、圖片、排序、星號、語言（朗讀用）、互換詞語與定義
- 匯入（Tab／逗號／自訂分隔）、匯出文字、資料夾、搜尋
- 學習模式：字卡（翻面、左右滑動分類、隨機、自動播放）、學習（選擇／是非／填寫、回合制）、
  測驗（是非／選擇／配對／填寫＋成績）、配對（計時＋最佳紀錄）、拼寫（語音）、重力遊戲
- 記憶複習：FSRS-5 演算法，可調目標保留率、每日上限、學習步驟；支援復原、略過、編輯卡片
- 統計（連續天數、熱度圖、7 天預測、卡片狀態）、深色模式、JSON 備份／還原

## 部署（需要 HTTPS 才能離線使用）
把整個資料夾放到任一靜態網站主機即可，例如：
- **GitHub Pages**：建立 repo 上傳所有檔案 → Settings → Pages → 選擇 main 分支
- **Netlify Drop**：到 app.netlify.com/drop 直接拖曳此資料夾

接著在 iPhone 用 Safari 開啟網址 → 分享 → 加入主畫面。

## 本機測試
```
python -m http.server 8765
```
然後開啟 http://localhost:8765

## 注意
資料只存在該裝置的瀏覽器中（主畫面 App 與 Safari 分開儲存），請在「設定」定期匯出備份。
更新程式後，到 `sw.js` 把 `CACHE` 版本號加一。
